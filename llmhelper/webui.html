Tiers

Restart the worker after changing settings or code — it loads the package once and keeps running what it started with.
Loading a tier unloads whatever is resident. A tier larger than free VRAM will load but run an order of magnitude slower.

Downloaded models

loading…
A model is only ever run through a tier, so a new download does nothing until you add it here. The new block is appended to the end of config.toml; everything above it is left untouched. Running servers pick it up without a restart. It is not the default for anything; you choose it with tier="name", and llmh bench --tier name measures it first.
